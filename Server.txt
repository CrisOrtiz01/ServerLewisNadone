## 🎯 CONCEPTO DEL SERVIDOR

Este servidor es un RPG inmersivo y desafiante llamado "ServerLewisNadone" que está centrado en:

### CARACTERÍSTICAS PRINCIPALES:
- **Sistema de Misiones Progresivo**: 61+ misiones organizadas en 9 categorías temáticas
- **Mobs Custom Exclusivos**: 35+ mobs custom que reemplazan COMPLETAMENTE a los mobs vanilla
- **9 NPCs Principales**: Cada uno con personalidad única y habilidades específicas
- **Habilidades Permanentes**: Sistema de poderes por niveles (Fuerza I-X, Resistencia I-III, etc.)
- **Economía Física**: Basada en TOKEN_MISION e intercambio de items, sin dinero virtual
- **Sistema de Clanes**: Protecciones y comunidades usando ProtectionStones
- **Crossplay**: Soporte para Java y Bedrock Edition via Geyser + Floodgate

### FILOSOFÍA DE JUEGO:
- **Desafío Extremo**: Desde el primer día el mundo es hostil y desafiante
- **Cooperación**: Los nuevos jugadores NECESITAN formar grupos para sobrevivir
- **Progresión Inmersiva**: Cada habilidad se gana a través de misiones temáticas
- **Historia Profunda**: Lore de dioses antiguos, campeones y la maldición de los monstruos

## 👹 SISTEMA COMPLETO DE MOBS CUSTOM (35+ MOBS)

### CONFIGURACIÓN CRÍTICA DE MYTHICMOBS:

```yaml
# config-spawning.yml
DisableVanillaSpawns: true    # ✅ CRÍTICO: Solo aparecen mobs custom
GenerateSpawnPoints: false    # ✅ Control total de spawns
ReplaceObeysCap: false        # ✅ Sin límites de reemplazo

# config-general.yml
Language: es-MX               # ✅ Unificado con Quests plugin
ThreadPoolSize: -1            # ✅ Optimización automática
```

### CARACTERÍSTICAS UNIVERSALES DE TODOS LOS MOBS:

1. **Reemplazo Completo**: `SpawnOverride` con `ReplaceType: true`
2. **Drop TOKEN_MISION**: 34/35 mobs dropean TOKEN_MISION (moneda del servidor)
3. **Sin Drops Vanilla**: `PreventOtherDrops: true`
4. **Nombres Visibles**: `AlwaysShowName: true`
5. **No Despawn**: `Despawn: false`
6. **Habilidades Únicas**: Cada mob tiene skills personalizadas

## 🎯 MECÁNICAS ESPECIALES DE SPAWNING

### SISTEMA DE REEMPLAZO TOTAL:
```yaml
SpawnOverride:
  Type: [MOB_VANILLA]     # Tipo de mob a reemplazar
  Priority: 1-2           # Prioridad (2 para jefes especiales)
  ReplaceType: true       # Reemplazo completo
  Conditions:
    - always              # Siempre activo
```

### DISTRIBUCIÓN POR ALTURA:
- **Y >= 64 (Superficie)**: Zombies, Skeletons, Creepers, Spiders, Endermen, Pillagers
- **Y <= 64 (Cuevas)**: Cave Spiders, Silverfish, Slimes, Witches
- **Nether**: Wither Skeletons, Blazes, Ghasts, Magma Cubes, Piglins, Hoglins
- **End**: Endermen (mejorados), Shulkers, Endermites
- **Océanos**: Guardians, Elder Guardians, Drowned
- **Spawners**: TODOS los mobs custom aparecen en spawners

### BALANCE DE DIFICULTAD:
- **Mobs Comunes**: 2-4x vida vanilla, 2-3x daño vanilla
- **Mobs Raros**: 3-5x vida vanilla, 3-4x daño vanilla  
- **Jefes Menores**: 5-8x vida vanilla, 4-6x daño vanilla
- **Jefes Supremos**: 8-10x vida vanilla, 6-8x daño vanilla

### ECONOMÍA TOKEN_MISION:
- **Mobs Comunes**: 1-3 TOKEN_MISION
- **Mobs Intermedios**: 4-8 TOKEN_MISION
- **Mobs Raros**: 8-16 TOKEN_MISION
- **Jefes Menores**: 16-50 TOKEN_MISION
- **Jefes Supremos**: 100-500 TOKEN_MISION
