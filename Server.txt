## 🎯 CONCEPTO DEL SERVIDOR

Este servidor es un RPG inmersivo y desafiante llamado "ServerLewisNadone" que está centrado en:

### CARACTERÍSTICAS PRINCIPALES:
- **Sistema de Misiones Progresivo**: 61+ misiones organizadas en 9 categorías temáticas
- **Mobs Custom Exclusivos**: 35+ mobs custom que reemplazan COMPLETAMENTE a los mobs vanilla
- **9 NPCs Principales**: Cada uno con personalidad única y habilidades específicas
- **Habilidades Permanentes**: Sistema de poderes por niveles (Fuerza I-X, Resistencia I-III, etc.)
- **Economía Física**: Basada en TOKEN_MISION e intercambio de items, sin dinero virtual
- **Sistema de Clanes**: Protecciones y comunidades usando ProtectionStones
- **Crossplay**: Soporte para Java y Bedrock Edition via Geyser + Floodgate

### FILOSOFÍA DE JUEGO:
- **Desafío Extremo**: Desde el primer día el mundo es hostil y desafiante
- **Cooperación**: Los nuevos jugadores NECESITAN formar grupos para sobrevivir
- **Progresión Inmersiva**: Cada habilidad se gana a través de misiones temáticas
- **Historia Profunda**: Lore de dioses antiguos, campeones y la maldición de los monstruos

### CONFIGURACIÓN CRÍTICA DE MYTHICMOBS:

```yaml
# config-spawning.yml
DisableVanillaSpawns: true    # ✅ CRÍTICO: Solo aparecen mobs custom
GenerateSpawnPoints: false    # ✅ Control total de spawns
ReplaceObeysCap: false        # ✅ Sin límites de reemplazo

# config-general.yml
Language: es-MX               # ✅ Unificado con Quests plugin
ThreadPoolSize: -1            # ✅ Optimización automática
```

### CARACTERÍSTICAS UNIVERSALES DE TODOS LOS MOBS:

1. **Reemplazo Completo**: `SpawnOverride` con `ReplaceType: true`
2. **Drop TOKEN_MISION**: 34/35 mobs dropean TOKEN_MISION (moneda del servidor)
3. **Sin Drops Vanilla**: `PreventOtherDrops: true`
4. **Nombres Visibles**: `AlwaysShowName: true`
5. **No Despawn**: `Despawn: false`
6. **Habilidades Únicas**: Cada mob tiene skills personalizadas

## 🎯 MECÁNICAS ESPECIALES DE SPAWNING

### SISTEMA DE REEMPLAZO TOTAL:
```yaml
SpawnOverride:
  Type: [MOB_VANILLA]     # Tipo de mob a reemplazar
  Priority: 1-2           # Prioridad (2 para jefes especiales)
  ReplaceType: true       # Reemplazo completo
  Conditions:
    - always              # Siempre activo
```

### DISTRIBUCIÓN POR ALTURA:
- **Y >= 64 (Superficie)**: Zombies, Skeletons, Creepers, Spiders, Endermen, Pillagers
- **Y <= 64 (Cuevas)**: Cave Spiders, Silverfish, Slimes, Witches
- **Nether**: Wither Skeletons, Blazes, Ghasts, Magma Cubes, Piglins, Hoglins
- **End**: Endermen (mejorados), Shulkers, Endermites
- **Océanos**: Guardians, Elder Guardians, Drowned
- **Spawners**: TODOS los mobs custom aparecen en spawners

### BALANCE DE DIFICULTAD:
- **Mobs Comunes**: 2-4x vida vanilla, 2-3x daño vanilla
- **Mobs Raros**: 3-5x vida vanilla, 3-4x daño vanilla  
- **Jefes Menores**: 5-8x vida vanilla, 4-6x daño vanilla
- **Jefes Supremos**: 8-10x vida vanilla, 6-8x daño vanilla

### ECONOMÍA TOKEN_MISION:
- **Mobs Comunes**: 1-3 TOKEN_MISION
- **Mobs Intermedios**: 4-8 TOKEN_MISION
- **Mobs Raros**: 8-16 TOKEN_MISION
- **Jefes Menores**: 16-50 TOKEN_MISION
- **Jefes Supremos**: 100-500 TOKEN_MISION

## 🎯 MECÁNICAS DE INTERACCIÓN DE NPCs

### SISTEMA DE COMANDOS AUTOMÁTICOS:
```yaml
Cada NPC ejecuta automáticamente:
1. Mensaje de saludo personalizado
2. Explicación de su especialidad
3. Descripción de niveles de misión disponibles
4. Comando: /q category [categoria]
5. Cooldown para evitar spam
```

### SISTEMA DE HOLOGRAMAS:
- **Línea 1**: Nombre del NPC (coloreado por especialidad)
- **Línea 2**: Título descriptivo de su maestría
- **Línea 3**: Frase característica o especialidad

### EQUIPAMIENTO TEMÁTICO:
Cada NPC porta equipment relacionado con su especialidad:
- **Erika**: Arco (caza)
- **Marta**: Espada + Escudo + Casco (defensa)
- **Sae**: Poción (curación)
- **Lia**: Papel (mensajería)
- **Ícaro**: Bastón (acrobacia)
- **Paúl**: Pico + Casco (minería)
- **Helena**: Azada dorada (curación)
- **Tomás**: Espada + Pectoral dorado (liderazgo)
- **Bruno**: Espada de madera + Gorro (cocina)

### PERSONALIDADES DIFERENCIADAS:
- **Erika**: Directa y orientada al combate
- **Marta**: Protectora y seria
- **Sae**: Gentil y sabia
- **Lia**: Energética y apresurada (cooldown menor)
- **Ícaro**: Alegre y aventurera
- **Paúl**: Veterano y tosco (menciona edad)
- **Helena**: Espiritual y maternal
- **Tomás**: Formal y heroico (cooldown mayor)
- **Bruno**: Acogedor y entusiasta por la comida

```yaml
# config.yml Quests
language: es-MX                    # ✅ Idioma unificado con MythicMobs
allow-command-questing: true       # ✅ Permite comandos en quest
allow-command-quests-with-npcs: true # ✅ Integración NPC-Quest
confirm-accept: true               # ✅ Confirmación al aceptar
max-quests: 0                      # ✅ Sin límite de quests simultáneas
storage-method: yaml               # ✅ Almacenamiento en archivos YAML
```

### FORMATO MODERNO DE MISIONES:
```yaml
# Nuevo formato implementado (corregido de legacy)
nombre_quest:
  name: 'Nombre Visible'
  ask-message: 'Diálogo inicial del NPC'
  finish-message: 'Diálogo de finalización'
  requirements:               # Requisitos para acceder
    level: 0
    permission: habilidades.x.y
    quest-points: número
    quests-completed: [quest_anterior]
  stages:                     # ✅ Objetivos organizados
    ordered:
      1:
        amounts-to-collect: [cantidad1, cantidad2]
        items-to-collect: [ITEM1, ITEM2]
        mob-amounts: [cantidad1, cantidad2]
        mobs-to-kill: [Mob_Custom1, Mob_Custom2]
  rewards:                    # ✅ Solo recompensas aquí
    commands: ['effect give %player% efecto 999999 nivel true']
    items: ['TOKEN_MISION:cantidad']
    permission: habilidades.especialidad.nivel
    quest-points: puntos
  options:
    cooldown:
      enabled: true
      time: 86400            # 24 horas
```

**NÁPOLES - EL PUEBLO CENTRAL**

Nápoles no es solo un pueblo, es el último bastión de esperanza en un mundo que ha sido corrompido por fuerzas antiguas. Este asentamiento, fundado por dos campeones legendarios hace generaciones incontables, se mantiene como un faro de civilización en medio de la oscuridad.

### 📜 LA HISTORIA COMPLETA:

**LOS TIEMPOS PRIMITIVOS**
```
Hace milenios, cuando la tierra era joven y salvaje, dos figuras legendarias 
caminaron entre los mortales. Uno dominaba la sabiduría y el ingenio; el otro, 
la fuerza y el valor. Unidos no por sangre sino por propósito, estos campeones 
fundaron un asentamiento a orillas de un valle fértil: Nápoles.

Su legado no fueron solo piedras y mortero, sino conocimiento. Enseñaron el 
arte de la caza, la forja, la medicina y la convivencia. Lo que comenzó como 
un simple refugio para viajeros se transformó en un pueblo próspero donde la 
paz y la esperanza echaron raíces profundas.
```

**LA GRAN CORRUPCIÓN**
```
Pero el tiempo es cruel incluso con los más grandes. Tras la muerte de los 
campeones, las fuerzas primordiales que una vez controlaron comenzaron a 
despertar. La magia antigua del mundo se corrompió, y las criaturas que 
habitaban en bosques, montañas y cavernas comenzaron a mutar y fortalecerse.

Los monstruos ya no eran simples bestias: se convirtieron en abominaciones 
endurecidas por siglos de exposición a la magia corrupta. Cada generación que 
pasaba, se volvían más fuertes, más inteligentes, más letales.
```

**EL LLAMADO DE LOS EXTRANJEROS**
```
Hoy, nuevas generaciones de extranjeros han comenzado a llegar a este mundo. 
Hombres y mujeres sin tierra, sin recuerdos de su pasado, llamados por un 
destino mayor: sobrevivir y conquistar lo que los antiguos no pudieron.

Estos forasteros no son comunes. Algunos poseen una chispa especial, una 
conexión con las fuerzas primordiales que les permite absorber y canalizar 
fragmentos del poder de los dioses antiguos.
```

**LLEGADA A NÁPOLES**
```
Cuando un extranjero llega por primera vez a Nápoles, se encuentra con un 
pueblo próspero pero claramente asediado. Los aldeanos trabajan con 
determinación, pero sus ojos muestran el peso de generaciones de constante 
amenaza.

Los nueve líderes no son simplemente maestros de habilidades: son mentores 
que guían a cada extranjero en un viaje de transformación personal. Cada 
misión completada no solo otorga poder, sino que teje al jugador más 
profundamente en la narrativa del mundo.
```

**PROGRESIÓN NARRATIVA**
```
- Niveles 1-3: El extranjero demuestra su valía básica
- Niveles 4-6: Se convierte en defensor reconocido del pueblo  
- Niveles 7-9: Alcanza el estatus de héroe local legendario
- Nivel 10: Trasciende los límites mortales, rivalizando con los dioses antiguos
```

**EL DESAFÍO MÁXIMO**
```
El mundo está diseñado para que ningún jugador pueda dominarlo por completo 
en solitario. Los jefes supremos - el Wither Supremo, el Dragón del End, y 
otros titanes - requieren no solo habilidad individual extrema, sino 
coordinación grupal y recursos masivos.

Esta filosofía impulsa la formación natural de clanes, pueblos, municipios 
y ciudades, recreando el espíritu cooperativo que una vez permitió a los 
campeones originales establecer Nápoles.
```
