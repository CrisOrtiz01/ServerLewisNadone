## 🎯 METAS Y OBJETIVOS DEL SERVIDOR

Este servidor RPG llamado "ServerLewisNadone" tiene como objetivo crear una experiencia inmersiva y desafiante mediante:

### METAS PRINCIPALES DE PROGRAMACIÓN:
- **Sistema de Progresión Revolucionario**: Programar 61+ misiones que otorguen habilidades permanentes como recompensa
- **Reemplazo Completo de Mobs**: Desarrollar 35+ mobs custom que sustituyan TOTALMENTE el sistema vanilla
- **NPCs Interactivos Complejos**: Crear 9 NPCs principales con personalidades únicas y sistemas de diálogo
- **Economía Física Innovadora**: Programar un sistema económico basado en items físicos sin dinero virtual
- **Sistema de Comunidades**: Implementar clanes, pueblos, municipios y ciudades con roles funcionales
- **Crossplay Avanzado**: Integrar soporte nativo para Java y Bedrock Edition

### FILOSOFÍA DE DESARROLLO:
- **Desafío desde el Inicio**: Programar la dificultad para que requiera cooperación desde el primer día
- **Progresión Narrativa**: Cada sistema debe contribuir a una historia cohesiva y envolvente
- **Interconexión Total**: Todos los sistemas (mobs, quests, NPCs, economía) deben estar interrelacionados
- **Escalabilidad**: Diseñar la arquitectura para permitir expansión futura del contenido

## 🏗️ ARQUITECTURA DE PROGRAMACIÓN DEL SERVIDOR

### ESTRUCTURA TÉCNICA DE DESARROLLO:

```
ServerLewisNadone/
├── Core Systems (Sistemas Centrales)
│   ├── MythicMobs Integration (Mobs Customizados)
│   ├── Quests System (Sistema de Misiones)
│   ├── NPCs Management (Gestión de NPCs)
│   └── Economy Framework (Marco Económico)
│
├── Plugin Integration Layer (Capa de Integración)
│   ├── CrossPlay Support (Soporte Multiplataforma)
│   ├── Permissions System (Sistema de Permisos)
│   ├── World Protection (Protección del Mundo)
│   └── Data Storage (Almacenamiento de Datos)
│
└── Content Development (Desarrollo de Contenido)
    ├── Custom Mob Programming (35+ mobs únicos)
    ├── Quest Line Development (61+ misiones)
    ├── NPC Personality Systems (9 NPCs principales)
    └── Economic Balance Programming (Sistema de TOKEN_MISION)
```

### PLUGINS REQUERIDOS PARA DESARROLLO:

**NÚCLEO TÉCNICO:**
1. **MythicMobs v5.6.2** - Motor de mobs customizados
2. **Quests v4.7.1** - Sistema de misiones avanzado  
3. **ZNPCs v6.0.0** - NPCs interactivos complejos

**INFRAESTRUCTURA:**
4. **LuckPerms v5.4.137** - Sistema de permisos escalable
5. **ProtectionStones v2.10.4** - Sistema de clanes y protecciones
6. **EssentialsX v2.20.1** - Comandos base del servidor

**CROSSPLAY:**
7. **Geyser-Spigot v2.4.0** - Compatibilidad Bedrock
8. **Floodgate v2.2.4** - Autenticación cross-platform

**SOPORTE:**
9. **ProtocolLib v5.2.0** - Manipulación de paquetes
10. **PlaceholderAPI v2.11.6** - Variables dinámicas

### PRINCIPIOS DE PROGRAMACIÓN:

**1. Modularidad Total:**
- Cada sistema debe ser independiente pero interconectado
- Configuraciones centralizadas para fácil mantenimiento
- APIs internas para comunicación entre plugins

**2. Escalabilidad:**
- Sistema de quest categories extensible
- Framework de mobs que permita agregar nuevos tipos
- Economía balanceada para cualquier número de jugadores

**3. Rendimiento:**
- Spawning optimizado para 35+ mobs custom simultáneos
- Caching inteligente de datos de misiones
- Gestión eficiente de memoria para NPCs

**4. Integración Seamless:**
- Todos los plugins deben funcionar como un sistema unificado
- UI/UX consistente a través de todos los componentes
- Narrativa coherente en todos los elementos

## 🔌 LISTA COMPLETA DE PLUGINS INSTALADOS

### PLUGINS PRINCIPALES (NÚCLEO DEL SERVIDOR):

1. **MythicMobs v5.6.2**
   - **Función**: Sistema de mobs custom que reemplaza COMPLETAMENTE a los mobs vanilla
   - **Configuración crítica**: `DisableVanillaSpawns: true`
   - **35+ mobs custom configurados** con habilidades únicas, stats balanceados y drops de TOKEN_MISION

2. **Quests v4.7.1**
   - **Función**: Sistema de misiones progresivo con 61+ misiones organizadas
   - **9 categorías temáticas** vinculadas a cada NPC principal
   - **Recompensas**: Habilidades permanentes (efectos de poción infinitos)

3. **ZNPCs v6.0.0**
   - **Función**: Sistema de NPCs interactivos con personalidades únicas
   - **9 NPCs principales** cada uno con diálogos específicos y vínculos a categorías de quest
   - **Hologramas descriptivos** y equipamiento temático

### PLUGINS DE INFRAESTRUCTURA:

4. **EssentialsX v2.20.1**
   - **Función**: Comandos básicos del servidor, teletransportes, homes, warps
   - **Configuración temática** para el servidor RPG
   - **Mensajes personalizados** en español

5. **LuckPerms v5.4.137**
   - **Función**: Sistema avanzado de permisos y grupos
   - **Configuración**: Permisos específicos para habilidades por niveles
   - **Storage**: H2 Database local

6. **ProtectionStones v2.10.4**
   - **Función**: Sistema de clanes, pueblos, municipios y ciudades
   - **Bloques de protección** configurables para diferentes tamaños
   - **Roles**: Alcalde, constructor, explorador, guardia, granjero

### PLUGINS DE CROSSPLAY:

7. **Geyser-Spigot v2.4.0**
   - **Función**: Permite jugadores de Bedrock Edition
   - **Configuración**: `auth-type: floodgate`

### CONFIGURACIÓN CRÍTICA DE MYTHICMOBS:

```yaml
# config-spawning.yml
DisableVanillaSpawns: true    # ✅ CRÍTICO: Solo aparecen mobs custom
GenerateSpawnPoints: false    # ✅ Control total de spawns
ReplaceObeysCap: false        # ✅ Sin límites de reemplazo

# config-general.yml
Language: es-MX               # ✅ Unificado con Quests plugin
ThreadPoolSize: -1            # ✅ Optimización automática
```

### CARACTERÍSTICAS UNIVERSALES DE TODOS LOS MOBS:

1. **Reemplazo Completo**: `SpawnOverride` con `ReplaceType: true`
2. **Drop TOKEN_MISION**: 34/35 mobs dropean TOKEN_MISION (moneda del servidor)
3. **Sin Drops Vanilla**: `PreventOtherDrops: true`
4. **Nombres Visibles**: `AlwaysShowName: true`
5. **No Despawn**: `Despawn: false`
6. **Habilidades Únicas**: Cada mob tiene skills personalizadas

```java
    // Personalidades y diálogos
    private Map<String, NPCPersonality> personalities;
    
    // Sistema de interacción
    public void handleNPCInteraction(Player player, NPC npc) {
        NPCPersonality personality = personalities.get(npc.getId());
        
        if (hasAvailableQuests(player, npc)) {
            showQuestDialogue(player, npc, personality);
        } else if (hasCompletableQuests(player, npc)) {
            showCompletionDialogue(player, npc, personality);
        } else {
            showIdleDialogue(player, npc, personality);
        }
    }
    
    // Sistema de quest integration
    private void showQuestDialogue(Player player, NPC npc, NPCPersonality personality) {
        List<Quest> available = getAvailableQuests(player, npc);
        String dialogue = personality.generateQuestOffering(available);
        sendFormattedMessage(player, dialogue);
        openQuestMenu(player, available);
    }
}
```

```java
    private final int EXCHANGE_RATE = 8; // 8 TOKEN = 1 Esmeralda Real
    
    // Drop system para mobs
    public void handleMobDeath(EntityDeathEvent event) {
        if (isCustomMob(event.getEntity())) {
            Player killer = event.getEntity().getKiller();
            if (killer != null) {
                dropTokenMision(event.getLocation(), getTokenAmount(event.getEntity()));
                trackEconomicActivity(killer, "mob_kill", getTokenAmount(event.getEntity()));
            }
        }
    }
    
    // Sistema de intercambio
    public boolean exchangeTokens(Player player, int tokenAmount) {
        int emeraldAmount = tokenAmount / EXCHANGE_RATE;
        if (emeraldAmount > 0 && hasTokens(player, tokenAmount)) {
            removeTokens(player, tokenAmount);
            giveEmeralds(player, emeraldAmount);
            logTransaction(player, tokenAmount, emeraldAmount);
            return true;
        }
        return false;
    }
}
```

## 📖 LORE COMPLETO Y NARRATIVA DEL SERVIDOR

### 🌍 EL MUNDO DE SERVERLEWISNADONE

**NÁPOLES - EL PUEBLO CENTRAL**

Nápoles no es solo un pueblo, es el último bastión de esperanza en un mundo que ha sido corrompido por fuerzas antiguas. Este asentamiento, fundado por dos campeones legendarios hace generaciones incontables, se mantiene como un faro de civilización en medio de la oscuridad.

### 📜 LA HISTORIA COMPLETA:

**LOS TIEMPOS PRIMITIVOS**
```
Hace milenios, cuando la tierra era joven y salvaje, dos figuras legendarias 
caminaron entre los mortales. Uno dominaba la sabiduría y el ingenio; el otro, 
la fuerza y el valor. Unidos no por sangre sino por propósito, estos campeones 
fundaron un asentamiento a orillas de un valle fértil: Nápoles.

Su legado no fueron solo piedras y mortero, sino conocimiento. Enseñaron el 
arte de la caza, la forja, la medicina y la convivencia. Lo que comenzó como 
un simple refugio para viajeros se transformó en un pueblo próspero donde la 
paz y la esperanza echaron raíces profundas.
```

**LA GRAN CORRUPCIÓN**
```
Pero el tiempo es cruel incluso con los más grandes. Tras la muerte de los 
campeones, las fuerzas primordiales que una vez controlaron comenzaron a 
despertar. La magia antigua del mundo se corrompió, y las criaturas que 
habitaban en bosques, montañas y cavernas comenzaron a mutar y fortalecerse.

Los monstruos ya no eran simples bestias: se convirtieron en abominaciones 
endurecidas por siglos de exposición a la magia corrupta. Cada generación que 
pasaba, se volvían más fuertes, más inteligentes, más letales.
```

**EL LLAMADO DE LOS EXTRANJEROS**
```
Hoy, nuevas generaciones de extranjeros han comenzado a llegar a este mundo. 
Hombres y mujeres sin tierra, sin recuerdos de su pasado, llamados por un 
destino mayor: sobrevivir y conquistar lo que los antiguos no pudieron.

Estos forasteros no son comunes. Algunos poseen una chispa especial, una 
conexión con las fuerzas primordiales que les permite absorber y canalizar 
fragmentos del poder de los dioses antiguos.
```

---

### 🏛️ LOS NUEVE LÍDERES DE NÁPOLES

Cada NPC representa un aspecto fundamental de la supervivencia y el progreso en este mundo hostil:

**TOMÁS, EL ALCALDE** 
```
Descendiente directo de los fundadores, Tomás mantiene viva la memoria de los 
campeones originales. Su conocimiento sobre liderazgo y protección de 
comunidades es inigualable. Quienes aprenden de él obtienen el reconocimiento 
eterno de los aldeanos: el título de Héroe de Villa.
```

**ERIKA, LA CAZADORA**
```
La más temida y respetada guerrera de Nápoles. Sus técnicas de combate han 
sido refinadas a través de décadas enfrentando las criaturas más peligrosas. 
Su entrenamiento no solo fortalece el cuerpo, sino que despierta la fuerza 
primordial que duerme en los huesos de los guerreros destinados.
```

**MARTA, LA GUARDIANA**
```
Protectora incansable del pueblo, Marta conoce los secretos de la resistencia 
absoluta. Su entrenamiento enseña no solo a soportar golpes, sino a convertir 
el propio cuerpo en una fortaleza impenetrable.
```

**SAE, LA SANADORA**
```
Discípula de los ángeles caídos, Sae posee conocimientos sobre la expansión 
de la fuerza vital. Sus enseñanzas permiten a los aventureros expandir su 
esencia misma, aumentando su capacidad de vida más allá de los límites mortales.
```

**LIA, LA MENSAJERA**
```
La más veloz de todos los mortales conocidos. Su entrenamiento desafía las 
leyes de la física, enseñando a canalizar la energía del viento y la tormenta 
para alcanzar velocidades inhumanas.
```

**ÍCARO, EL ACRÓBATA**
```
Maestro de los imposibles, Ícaro desafía la gravedad misma. Sus técnicas 
permiten a los estudiantes dominar el arte del movimiento tridimensional, 
convirtiendo el mundo entero en su escenario.
```

**PAÚL, EL MINERO**
```
Veterano de las profundidades, Paúl ha pasado décadas explorando las entrañas 
de la tierra. Su conocimiento sobre la extracción de recursos es legendario, 
y su entrenamiento permite a las manos moverse a velocidades sobrenaturales 
cuando empuñan herramientas de minería.
```

**HELENA, LA CURANDERA**
```
Guardiana de los conocimientos ancestrales de curación, Helena enseña el arte 
de la regeneración continua. Sus estudiantes aprenden a acelerar sus procesos 
naturales de sanación hasta niveles milagrosos.
```

**BRUNO, EL CHEF**
```
Maestro de la alquimia culinaria, Bruno conoce los secretos de la nutrición 
perfecta. Sus enseñanzas permiten al cuerpo mantener un estado de saciedad 
y energía constante, eliminando la necesidad de comer frecuentemente.
```

### ⚡ LOS DIOSES ANTIGUOS Y NUEVOS

**LOS ÁNGELES PRIMORDIALES**
```
Las estatuas en el Altar de los Ángeles no son meras decoraciones. Son 
monumentos a seres que una vez caminaron por esta tierra, cuando la línea 
entre lo mortal y lo divino era más difusa. 

Estos ángeles y titanes reinaron antes de la llegada de los campeones, y 
sus fragmentos de poder aún permean el mundo. Las habilidades que los 
mortales pueden obtener son ecos de estas fuerzas primordiales.
```

**LA MALDICIÓN DE LOS MONSTRUOS**
```
Los monstruos que infestan el mundo no son simples bestias: son el resultado 
directo de la corrupción de los dioses antiguos. Cada criatura abatida libera 
fragmentos de esta corrupción cristalizada: los Tokens de Misión.

Estos tokens son prueba tangible de la lucha contra las fuerzas oscuras. 
Cuando son purificados y transformados en Esmeraldas Reales, se convierten 
en la única moneda reconocida en Nápoles.
```

**EL PODER DE LOS EXTRANJEROS**
```
Los recién llegados poseen algo que los nativos han perdido: la capacidad 
de absorber y canalizar el poder corrupto sin ser consumidos por él. Esta 
capacidad los convierte en los únicos capaces de enfrentar las amenazas 
crecientes y restaurar el equilibrio al mundo.
```

### 🌟 LA EXPERIENCIA COMPLETA DEL JUGADOR

**LLEGADA A NÁPOLES**
```
Cuando un extranjero llega por primera vez a Nápoles, se encuentra con un 
pueblo próspero pero claramente asediado. Los aldeanos trabajan con 
determinación, pero sus ojos muestran el peso de generaciones de constante 
amenaza.

Los nueve líderes no son simplemente maestros de habilidades: son mentores 
que guían a cada extranjero en un viaje de transformación personal. Cada 
misión completada no solo otorga poder, sino que teje al jugador más 
profundamente en la narrativa del mundo.
```

**PROGRESIÓN NARRATIVA**
```
- Niveles 1-3: El extranjero demuestra su valía básica
- Niveles 4-6: Se convierte en defensor reconocido del pueblo  
- Niveles 7-9: Alcanza el estatus de héroe local legendario
- Nivel 10: Trasciende los límites mortales, rivalizando con los dioses antiguos
```

**EL DESAFÍO MÁXIMO**
```
El mundo está diseñado para que ningún jugador pueda dominarlo por completo 
en solitario. Los jefes supremos - el Wither Supremo, el Dragón del End, y 
otros titanes - requieren no solo habilidad individual extrema, sino 
coordinación grupal y recursos masivos.

Esta filosofía impulsa la formación natural de clanes, pueblos, municipios 
y ciudades, recreando el espíritu cooperativo que una vez permitió a los 
campeones originales establecer Nápoles.
```

### 🌍 CONSTRUCCIÓN DEL MUNDO FÍSICO

**NÁPOLES - DISEÑO RECOMENDADO**
```
El pueblo debe reflejar su rica historia y su función como último bastión:

Centro del Pueblo:
- Plaza central con fuente (símbolo de vida en medio de la desolación)
- Mercado con puestos de comerciantes NPCs
- Monumento a los Campeones Fundadores

Barrio Residencial:
- 9 casas temáticas para cada líder NPC
- Cada casa refleja la personalidad y especialidad del habitante
- Jardines comunitarios y talleres especializados

Altar de los Ángeles:
- Bosque sagrado a las afueras del pueblo
- Estatuas de ángeles y titanes primordiales
- Ambiente místico y solemne
- Lugar de reflexión y respeto al lore
```

**AMBIENTE Y ESTÉTICA**
```
- Arquitectura medieval fantástica con influencias de múltiples culturas
- Materiales: Piedra, madera, algunos toques de metales preciosos
- Iluminación: Antorchas, linternas, cristales brillantes
- Vegetación: Jardines bien cuidados vs. naturaleza salvaje circundante
- Contraste: Orden y belleza del pueblo vs. peligro del mundo exterior
```
